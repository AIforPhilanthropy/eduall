# EduAll Grant Allocation in AnythingLLM

## Download (one click, all files)

**[Download setup_package_anythingllm.zip](https://github.com/AIforPhilanthropy/eduall/raw/main/anythingllm/setup_package_anythingllm.zip)**

The download starts immediately. Unzip it (double-click on Windows and Mac). Inside the unzipped folder, open the guide in your language:

- English: `START_HERE_EN.md`
- Italiano: `START_HERE_IT.md`

The zip contains the data skill (applicants and applications), the independent-review flow, the foundation documents to upload, and the assistant's instructions. No coding or extra software is needed beyond AnythingLLM Desktop.
